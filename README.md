Ejercicio 2.E.2 01 - Artículo Geek

Lógica del programa
Para resolver este primer ejercicio de la nueva etapa, diseñé una clase sencilla llamada `ArticuloGeek` que contiene dos atributos de acceso directo: `nombre` (de tipo String) y `precioBase` (de tipo double). Al no definir un constructor específico, la clase utiliza el constructor por defecto de Java.

En un archivo separado, dentro de la clase `Main` y su respectivo método principal, implementé la siguiente lógica:
1. Instancié dos objetos independientes a partir de la clase `ArticuloGeek` (`ag1` y `ag2`).
2. Al no tener encapsulamiento, accedí a los atributos directamente para asignarles sus valores (a `ag1` le definí el nombre "Figura de Miku" y un precio base de 67000, y a `ag2` le asigné "Tomo de manga" con un valor de 15000).
3. Imprimí los resultados por consola concatenando texto fijo con los atributos de cada objeto para verificar que los datos se almacenaron correctamente en sus respectivas instancias.
